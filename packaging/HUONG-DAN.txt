KOL Fashion MASYS Video vVERSION — hướng dẫn nhanh
=======================================

Cần có: máy Windows 10/11 đã cài Google Chrome, và file khoá Google (.json) người phụ trách gửi riêng cho bạn.

1. Giải nén toàn bộ file zip ra một thư mục bất kỳ (ví dụ Documents\KOL-Fashion-MASYS-Video). Đừng chạy thẳng trong file zip.
2. Bấm đúp Mo-MASYS.bat. Một cửa sổ đen hiện ra và trình duyệt tự mở trang tool.
   Đừng đóng cửa sổ đen khi đang dùng tool. Muốn tắt tool thì đóng cửa sổ đó.
   Nếu Windows hỏi "Windows protected your PC", bấm "More info" rồi "Run anyway".
3. Lần đầu: tool mở trang "Cài khoá Google". Chọn file khoá .json rồi bấm Lưu khoá. Tool tự khởi động lại.
   Khoá được mã hoá và cất trong máy, chỉ tài khoản Windows của bạn mở được. Có thể xoá file .json gốc sau bước này.
4. Làm tiếp các bước tool hiện trên màn hình (mỗi bước có dấu ✅ khi xong):
   dán link Google Sheet → đăng nhập Muse trong cửa sổ bot → dán link thư mục Drive lưu video.
5. Trên màn hình Bảng: tích các dòng cần làm rồi bấm "Tạo video". Cần giúp: ⚙ Nâng cao → Hướng dẫn.

Dữ liệu (lịch sử lô, cài đặt, phiên đăng nhập Muse, khoá đã mã hoá) nằm ở %LOCALAPPDATA%\masys-video,
không nằm trong thư mục này.

Cập nhật: khi có bản mới, trên đầu trang tool hiện "Có bản mới". Vào Cài đặt → Phiên bản, bấm "Cập nhật".
Tool tự tải, sao lưu dữ liệu rồi khởi động lại, không cần tải zip lại. Đừng sửa tay thư mục phien-ban.

Gặp lỗi: chụp màn hình cửa sổ đen và trang tool, gửi người phụ trách.
